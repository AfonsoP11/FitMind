# FitMind
🧠 FitMind  Encontre seu psicólogo, compare abordagens e agende sua consulta online ou presencial.  FitMind é um app web, em formato mobile, que conecta pessoas a psicólogos. Dá para buscar profissionais por abordagem e especialidade, ver perfis completos, escolher um horário livre no calendário e acompanhar as consultas agendadas.
